# 🍳 AI Recipe App  

An **AI-powered recipe application** that helps you discover and generate cooking recipes.  
Simply enter ingredients or a dish name, and the app will suggest recipes with step-by-step instructions.  

---

## 🚀 Features  
- 🔍 Search recipes by ingredients or dish name  
- 🤖 AI-generated recipes using OpenAI API  
- 🖼️ Recipe images (optional via image API)  
- 📖 Save and manage favorite recipes  
- 📱 Responsive design for mobile & desktop  

---

## 🛠️ Tech Stack  
- **Frontend:** React.js (with Tailwind CSS)  
- **Backend:** Node.js + Express  
- **Database:** MongoDB  
- **AI Integration:** OpenAI API  
- **Styling:** TailwindCSS
